### Cloud Security Assessment Framework | Python, AWS, GCP, Boto3


* Developed a **Python-based cloud security assessment tool** that automated **15+ security checks** across **AWS IAM Users, Roles, Policies, S3 Buckets, and EC2**, identifying excessive IAM permissions, publicly accessible storage, and cloud misconfigurations using the **Boto3** SDK.
* Built an automated **cloud asset discovery and network topology visualization** that mapped relationships between VPC resources, EC2 instances, Security Groups, and internet-exposed assets to improve attack surface visibility; implemented equivalent scanning support for **Google Cloud Platform (GCP)**.
* Validated the tool against **Flaws.Cloud**, successfully completing **all 5 challenge levels** while generating terminal-based security findings for vulnerable cloud resources.
